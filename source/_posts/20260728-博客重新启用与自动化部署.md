# 博客重新启用与自动化部署

好久没更新了。这次重新启用博客，顺手把整套发布流程改成了**免本地构建**的云端闭环，记录一下，也作为新流程的第一篇测试文章。

## 原来的麻烦

之前每次写文章，都得在本地装好 Node、Hexo，跑 `hexo g` 生成静态文件，再推到仓库。换台电脑、或者环境一乱，就又得折腾一遍。

## 现在的做法

博客源码放在 `source` 分支，GitHub Actions 负责构建和部署：

1. 用 Typora 本地编辑 `source/_posts/*.md`；
2. `git commit` + `git push` 到 `source` 分支；
3. 云端自动 `hexo g` 生成站点并发布到 `master`。

我本地不需要再装 Hexo，写好的 Markdown 一推送，站点就更新了。

## 本地预览（可选）

如果推送前想先看真实渲染效果：

```powershell
npx hexo server
# 访问 http://localhost:4000
```

## 小结

流程越简单，越容易坚持。希望这次能稳定更新下去。
